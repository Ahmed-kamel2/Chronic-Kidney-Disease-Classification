# Chronic-Kidney-Disease-Classification
# Chronic Kidney Disease Prediction System using Machine Learning, Data Analysis & Visualization

## Overview
This project presents a complete Machine Learning and Data Analysis system for predicting Chronic Kidney Disease (CKD) using medical patient data. The project focuses on data preprocessing, visualization, feature engineering, model comparison, and predictive analysis to evaluate different machine learning algorithms for healthcare classification problems.

The system was developed using Python and several machine learning and visualization libraries to analyze patient health indicators and classify kidney disease conditions accurately.

---

## Objectives
- Analyze medical data related to Chronic Kidney Disease
- Perform data preprocessing and cleaning
- Visualize relationships between medical features
- Compare multiple machine learning algorithms
- Evaluate model performance using classification metrics
- Build an interactive prediction system for patient testing

## Project Workflow

### 1. Data Preprocessing
- Handling missing values
- Feature selection
- Encoding categorical variables
- Data normalization and scaling

### 2. Data Analysis & Visualization
- Correlation analysis
- Heatmaps
- Distribution plots
- Pair plots
- Feature relationship analysis

### 3. Model Training
- Splitting dataset into training and testing sets
- Training multiple machine learning models
- Hyperparameter adjustments

### 4. Model Evaluation
Models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score

### 5. Prediction System
An interactive prediction section was developed to test patient data and generate disease classification predictions.
